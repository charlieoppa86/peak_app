## 최상위 탭 구조

탭 5개 → 3개로 간소화 (2026-06-08). 최근 캘린더/일정/소셜 앱 트렌드(Strava, Komoot 등)는
바텀 탭을 핵심 행동 축 3~4개로 좁히고, 알림처럼 "확인만 하면 되는" 보조 기능은 탭이 아닌
상단 바 아이콘(뱃지)으로 분리한다. Peak도 동일한 원칙을 적용:

- **홈·일정 통합**: 사용자가 "내 일정이 어떻게 되지?"라고 물을 때 캘린더·날씨·등록된 일정·완료 현황을
  한 화면에서 바로 봐야 한다는 피드백 반영 — 별도 탭으로 나눌 필요 없음
- **알림 → 전역 아이콘**: 알림은 머물러 탐색하는 공간이 아니라 잠깐 확인하고 빠지는 인박스이므로
  모든 화면 상단 바의 벨 아이콘(뱃지)으로 항상 접근 가능하게 유지 (Instagram/X/Airbnb 등과 동일 패턴)

| 탭 | 아이콘 역할 | 핵심 목적 |
|---|---|---|
| 홈 | 캘린더·일정·날씨 통합 | "내 일정이 어떻게 되지? 언제 더 탈까?"를 한 화면에서 확인·결정 |
| 그룹 | 초대·참석 | 같이 달리기 일정 관리 |
| 설정 | 지역·프로필·구독 | 개인화 및 플랜 관리 |

| 전역 요소 | 위치 | 핵심 목적 |
|---|---|---|
| 알림 | 모든 화면 상단 바 벨 아이콘(뱃지) → 전체화면 push | 날씨 악화·주간 요약·그룹 일정 변경 인박스 (US-007, US-008) |

## 홈 화면 컨셉 노트

### 핵심 UX 원칙

홈 화면은 날씨 정보 제공이 아닌 **"언제 탈까 → 혼자/같이 → 일정 확정"** 의사결정 흐름 그 자체.

### 고객 여정 (홈 화면 내)

```
캘린더 스캔 → 날짜 탭 → 날씨 확인 (인라인 펼침) → 혼자/같이 선택 → 일정 등록 → (초대 발송)
```

### 캘린더 UI 구조 (2026-06-07 업데이트)

일반 캘린더 앱과 동일한 월 단위 7열 격자 구조로 변경. 사용자에게 익숙한 멘탈 모델 활용.

| 항목 | 결정 | 근거 |
|---|---|---|
| 캘린더 레이아웃 | 월 단위 7열 격자 (일~토) | 기존 캘린더 앱과 동일한 구조 — 친숙한 멘탈 모델 |
| 셀 구성 | 날짜 숫자 + 점수 pill + 색상 배경 | 셀 전체 색상으로 스캔 속도 유지, pill로 구체 점수 확인 |
| 예보 범위 표시 | 2주치(14일) 색상 적용, 이후 날짜 dim 처리 | 예보 가능 범위를 시각적으로 명확히 구분 |
| 월 이동 | 좌우 화살표 네비게이션 | 달력 탐색 패턴과 동일, 미래 날짜 확인 가능 |
| 일정 dot 인디케이터 | 초록 dot = 혼자 일정, 노랑 dot = 그룹 일정 | 캘린더 앱 표준 패턴 — 일정 유무 즉시 파악 |
| 날짜 탭 구조 | 인라인 펼침 (화면 전환 없음) | 날씨 확인 → 일정 등록 흐름이 끊기지 않아야 함 |
| 혼자/같이 CTA 위치 | 날씨 확인 직후 인라인 노출 | 처음 쓰는 사람에게 서비스 핵심을 즉시 전달 |
| 점수 색상 기준 | 초록(80+) · 노랑(50~79) · 빨강(~49) | 스캔만으로 이번 주 패턴 파악 가능 |
| 테마 | 다크모드 기본 적용 | 점수 색상 가독성 — 셀 배경은 딥 톤, 점수 텍스트는 밝은 틴트로 분리 |

### Flutter 라우팅 참고 (2026-06-08 재구조화)

바텀 탭 3개(홈·그룹·설정) + `/notifications`는 탭 바깥의 전역 push 라우트 (모든 화면 상단 바 벨 아이콘에서 진입, 전체화면으로 열리며 바텀 탭은 숨김).
일정 등록/상세/수정은 홈 브랜치 하위 경로로 통합 — 같은 탭 안에서 스택만 깊어진다.

```
/onboarding              ← 온보딩 (탭 셸 밖)
/notifications           ← 알림 인박스 (탭 셸 밖, 전역 벨 아이콘 → push)

[바텀 탭 셸]
  /home                  ← 홈 (캘린더 + 일정 + 날씨 통합)
    /home/schedule/new        ← 일정 등록
    /home/schedule/:id        ← 일정 상세
    /home/schedule/:id/edit   ← 일정 수정
  /group                 ← 그룹 일정 목록
    /group/:id           ← 그룹 일정 상세
    /group/:id/edit      ← 그룹 일정 수정
  /settings              ← 설정 홈
    /settings/profile    ← 프로필 편집
    /settings/location   ← 지역 설정
    /settings/alerts     ← 알림 설정
    /settings/plan       ← 플랜 관리
      /settings/plan/referral ← 추천인 코드

[웹 — Firebase Hosting]
  /invite/:token         ← 초대 랜딩 (앱 외부)
```
