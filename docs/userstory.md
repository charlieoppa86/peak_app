## Onboarding — 앱을 처음 열고 내 상황을 설정하기까지

### US-001 · Must

**스토리**
> 로드바이커로서, 앱 첫 실행 시 이름·거주 지역·주요 운동 요일을 3단계 이내로 설정하고 싶다.
> 그래야 내 지역 날씨 기반 일정 추천을 바로 받을 수 있기 때문이다.

**Acceptance Criteria**
1. 이름·지역(시/구 단위)·선호 요일 입력 화면이 3개 이하 스텝으로 완료된다
2. 지역 설정 완료 즉시 해당 지역 2주 날씨 캘린더가 표시된다
3. 온보딩 완료 후 재실행 시 온보딩 화면이 다시 나타나지 않는다

### US-002 · Must ★수정 (2026-06-28)

**스토리**
> 로드바이커로서, 앱 첫 실행 시 로그인 없이 날씨 캘린더와 혼자 달리기(개인 일정)를 바로 사용하고 싶다.
> 그래야 가치를 확인하기 전 가입 마찰로 이탈하지 않으면서, 같이 달리기·공유처럼 신원이 필요한 기능에서만 로그인할 수 있기 때문이다.

**로그인 정책 (2026-06-28)**
- **로그인 불필요(익명 세션 유지)**: 날씨 캘린더 열람, 혼자 달리기 일정 등록/관리, 알림 수신
- **소셜 로그인 필요(게이트)**: 같이 달리기(그룹 일정) 생성, 일정/그룹 초대 공유
- 로그인 수단: **카카오**(전 플랫폼), **애플**(iOS 전용 — App Store 정책상 제3자 로그인 제공 시 애플 로그인 의무)
- 익명 세션으로 시작해 게이트 시점에 카카오/애플 로그인으로 **세션 승격**한다 (`isAnonymous == false`로 로그인 여부 판별)

**Acceptance Criteria**
1. 앱 첫 실행 시 계정 생성·로그인 없이 지역 설정만으로 메인 화면에 진입하고, 혼자 달리기 일정을 등록할 수 있다
2. '같이 달리기' 생성 또는 '초대하기/초대 공유'를 누르면 로그인 안 된 상태에서 로그인 시트(카카오·애플)가 뜨고, 로그인 성공 후 원래 동작이 이어진다
3. 한 번 로그인하면 세션이 유지되어 이후 같은 동작에서 로그인 시트가 다시 뜨지 않는다
4. 입력한 이름/닉네임은 기기에 저장되어 이후 초대 발송 시 자동으로 채워진다

## Activation — 핵심 가치를 처음 경험하는 순간

### US-003 · Must

**스토리**
> 로드바이커로서, 캘린더에서 날짜별 라이딩 점수(0~100)를 한눈에 보고 싶다.
> 그래야 별도 날씨 앱을 열지 않고 이번 주 최적 날을 바로 판단할 수 있기 때문이다.

**Acceptance Criteria**
1. 캘린더 셀에 점수(숫자)와 색상(초록·노랑·빨강 3단계)이 동시에 표시된다
2. 날짜를 탭하면 기온·강수확률·풍속 3가지 수치가 상세 표시된다
3. 오늘 기준 14일치 데이터가 앱 진입 3초 이내에 표시된다

**INVEST** `I:O` `N:O` `V:O` `E:O` `S:O` `T:O`

### US-004 · Must ★수정 (2026-06-07)

**스토리**
> 로드바이커로서, 홈 화면에서 날짜를 탭한 후 혼자/같이 중 선택해 출발 시간·코스명을 입력하고 30초 이내로 일정을 등록하고 싶다.
> 그래야 날씨 확인과 일정 등록이 한 흐름으로 완결될 수 있기 때문이다.

**Acceptance Criteria**
1. 날짜 탭 → 날씨 상세 인라인 펼침 → 혼자/같이 선택 → 일정 등록까지 화면 전환 없이 30초 이내 완료된다
2. 등록된 일정은 캘린더 셀에 점(dot) 인디케이터로 즉시 반영된다
3. 이전에 입력한 코스명이 드롭다운 즐겨찾기로 최대 5개까지 노출된다

**INVEST** `I:O` `N:O` `V:O` `E:O` `S:O` `T:O`

### US-005 · Must

**스토리**
> 로드바이커로서, 내 일정에 친구를 문자 한 통으로 초대하고 싶다.
> 그래야 카카오 단톡 없이도 같이 달릴 사람을 모을 수 있기 때문이다.

**Acceptance Criteria**

2. 공유 링크를 받은 사람이 링크를 열면 웹에서 일정 내용을 확인하고 이름 입력 후 참석 처리된다
3. 초대받은 사람이 참석을 선택하면 초대자의 일정 화면에 참석자 이름과 수가 실시간으로 업데이트된다

### US-006 · Must ★수정 (2026-06-07)

**스토리**
> 초대받은 비사용자로서, 링크를 열었을 때 앱 설치 없이 일정 내용을 확인하고 이름/닉네임만 입력해 참석 의사를 전달하고 싶다.
> 그래야 로그인 없이도 참석을 표시하고 초대자가 누가 오는지 바로 알 수 있기 때문이다.

**Acceptance Criteria**
1. 랜딩 웹페이지에서 일정 날짜·출발 시간·코스명·날씨 점수를 앱 없이 확인할 수 있다
2. '참석할게요' 버튼 탭 시 이름 또는 닉네임 입력 필드(1개)만 표시되며, 입력 완료 즉시 참석 처리된다
3. 참석 완료 화면 하단에 "다음 라이딩 날씨 알림 받기 → 앱 설치" 넛지가 1회 노출된다

## Retention — 다음 주에도 앱을 다시 열게 만드는 루프

### US-007 · Must

**스토리**
> 로드바이커로서, 내 예정 일정의 날씨가 크게 나빠지면 앱이 먼저 알려주고 대안 날짜를 1개 제안해 주길 원한다.
> 그래야 직접 날씨를 재확인하지 않아도 일정을 유연하게 조정할 수 있기 때문이다.

**Acceptance Criteria**
1. 등록 일정 기준 강수확률이 50%p 이상 상승하면 푸시 알림이 발송된다
2. 알림 본문에 "대신 [날짜] [시간]대가 점수 [N]점으로 좋아요" 형태의 대안 1건이 포함된다
3. 알림을 탭하면 대안 날짜가 미리 선택된 일정 편집 화면으로 바로 이동한다

**INVEST** `I:O` `N:O` `V:O` `E:O` `S:O` `T:O`

### US-008 · Must

**스토리**
> 로드바이커로서, 이번 주 라이딩 최적 시간대 TOP 3를 월요일 아침에 요약 알림으로 받고 싶다.
> 그래야 주초에 한 번만 확인하고 그 주 일정을 바로 잡을 수 있기 때문이다.

**Acceptance Criteria**
1. 매주 월요일 오전 8시에 해당 주 점수 상위 3개 날짜·시간대가 푸시로 발송된다
2. 알림 탭 시 해당 주 캘린더 뷰로 이동하며 TOP 3 날짜가 하이라이트된다
3. 사용자가 알림 설정에서 요일·시각을 변경하거나 끌 수 있다

**INVEST** `I:O` `N:O` `V:O` `E:O` `S:O` `T:O`

### US-009 · Must

**스토리**
> 로드바이커로서, 완료된 라이딩에 '완료' 체크를 찍어 이번 달 몇 번 탔는지 한눈에 보고 싶다.
> 그래야 운동 습관 유지 동기를 얻을 수 있기 때문이다.

**Acceptance Criteria**
1. 일정 상세 화면에서 '라이딩 완료' 버튼을 탭하면 해당 일정이 완료 상태로 전환된다
2. 이번 달 완료 횟수가 메인 화면 상단에 "이번 달 N회 완료" 형태로 표시된다
3. 완료 처리된 날짜는 캘린더에서 시각적으로 구분된다 (예: 체크 아이콘)

### US-010 · Should

**스토리**
> 그룹 라이딩 오거나이저로서, 날씨 변동 시 그룹 멤버 전원에게 새 일정을 한 번에 재공지하고 싶다.
> 그래야 단톡방 공지 없이도 멤버 전원이 변경 사항을 즉시 확인할 수 있기 때문이다.

**Acceptance Criteria**
1. 오거나이저가 그룹 일정 날짜를 변경하면 참석 수락한 멤버 전원에게 변경 푸시가 발송된다
2. 멤버는 변경된 일정에 재응답(참석 유지·불참 전환)할 수 있다
3. 오거나이저 화면에서 재응답 현황(참석 N명·미응답 N명)이 실시간으로 표시된다

**INVEST** `I:O` `N:O` `V:O` `E:O` `S:O` `T:O`

### US-011 · Should

**스토리**
> 로드바이커로서, 알림 수신 시간대와 날씨 점수 기준(민감도)을 직접 조정하고 싶다.
> 그래야 과도한 알림으로 인한 피로 없이 나에게 맞는 수준의 정보를 받을 수 있기 때문이다.

3. 변경 사항이 저장되면 다음 알림 발송 시점부터 즉시 적용된다

## Revenue — 지불 의사를 만드는 경험

3. 잠금 화면에서 "7일 무료 체험" CTA가 1회 노출된다
